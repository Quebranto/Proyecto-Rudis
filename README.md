# 🏛️ PROJECT RUDIS — STATEOS, RUDIS HABITAT & INSTITUTIONAL INFRASTRUCTURE

**No pedimos que crea que Rudis funciona. Le entregamos una arquitectura diseñada para que pueda ser auditada, contradicha y, cuando sea posible, rota de forma reproducible.**

Rudis es un proyecto experimental de **arquitectura constitucional, sistemas distribuidos e infraestructura institucional** orientado a un problema central:

> **Una representación del estado no adquiere autoridad sobre la realidad simplemente por afirmar que la representa.**

Rudis investiga cómo humanos, agentes, instituciones, clientes, mundos interactivos y sistemas externos pueden compartir un estado institucional persistente sin permitir que una interfaz, un proveedor, una sesión, una clave o una capacidad técnica se conviertan silenciosamente en autoridad.

```text
CAPABILITY != AUTHORITY
IDENTITY != COMPETENCE
REPRESENTATION != AUTHORITY
TECHNICAL EXECUTION != POLITICAL SOVEREIGNTY
```

---

## 🌍 QUÉ ESTÁ CONSTRUYENDO RUDIS

### StateOS

Una arquitectura para mantener una cadena causal explícita entre:

```text
IDENTIDAD / CLAIM
-> COMPETENCIA / AUTORIDAD
-> REGLA / LEY
-> DECISIÓN / MANDATO
-> EJECUCIÓN
-> EFECTO / RECEIPT
-> CONTINUIDAD
-> AUDITORÍA
```

El objetivo no es sustituir Estados, gobiernos, empresas, plataformas o infraestructuras externas.

```text
SYSTEM != STATE
INTEROPERABILITY != GOVERNANCE
```

StateOS se concibe como **infraestructura institucional complementaria**.

### Rudis Habitat

La capa habitable de StateOS: un mundo institucional persistente capaz de expresarse mediante múltiples superficies —web, móvil, VR/MR, motores 3D, agentes, APIs y futuras interfaces— sin convertir ninguna superficie en raíz soberana.

```text
ONE CAUSAL INSTITUTIONAL STATE
-> MANY LEGITIMATE REPRESENTATIONS
```

### Rudis Authority Layer (RAL)

Una superficie arquitectónica enfocada en el límite entre intención y ejecución consecuencial:

```text
AGENT / CLIENT
-> INTENT
-> AUTHORITY / RULE RESOLUTION
-> MANDATE
-> EFFECT
-> RECEIPT
```

RAL es una vía de producto / integración dentro de la obra más amplia; no sustituye al conjunto de Rudis.

## 🧭 DOS SUPERFICIES, UNA OBRA

Rudis separa deliberadamente:

### Superficie pública

`Quebranto/Proyecto-Rudis` contiene el Corpus, arquitectura, decisiones públicas, investigación, contratos no sensibles, políticas de publicación y materiales externos.

### Superficie privada autorizada

La implementación operativa y los detalles técnicos sensibles permanecen en una superficie privada de acceso controlado.

No se publican por defecto localizadores privados, topología, ramas, credenciales, internals sensibles, rutas de explotación ni información operacional innecesaria.

```text
TRANSPARENCY != UNRESTRICTED OPERATIONAL DISCLOSURE
```

## ⚖️ REGLA DE INGENIERÍA CONSTITUCIONAL

Rudis mantiene una frontera estricta entre norma, competencia, ejecución, auditoría y resolución.

La regla central es:

> **El código ejecuta competencias previamente reconocidas; nunca inventa la ley que le falta.**

Cuando falta una decisión constitucional necesaria:

```text
UNRESOLVED_CONSTITUTIONAL_DEPENDENCY
```

antes que:

```text
ENGINEERING CONVENIENCE -> NEW LAW
```

## 🔄 CONTINUIDAD, RECOVERY Y RECONSTITUCIÓN

Rudis investiga restart, replay, currentness, revocación, continuidad cívica y reconstrucción post-catástrofe.

Principios actuales:

```text
RECOVER STATE != RECOVER AUTHORITY
HISTORICAL VALIDITY != CURRENT AUTHORITY
SNAPSHOT INTEGRITY != CURRENTNESS
RECONSTRUCTION != AUTHORITY RESURRECTION
```

El Palacio de Unificación tiene además una misión canónica de reconstitución catastrófica: Rudis debe conservar la capacidad de volver a encontrarse a sí mismo a partir de fragmentos auténticos suficientes sin fabricar continuidad ni resucitar poder muerto.

## 🏛️ ARQUITECTURA INSTITUCIONAL

El Corpus distingue, entre otros, funciones de:

- dirección fundacional;
- Asamblea y deliberación colectiva;
- creación y versionado normativo;
- ejecución mediante Gremios;
- auditoría y adversarial testing mediante el Palacio de Tormentas;
- investigación y aprendizaje mediante el Palacio Evolutivo;
- diligencia, integración y reconstitución mediante el Palacio de Unificación;
- resolución de controversias mediante el órgano competente;
- asesoramiento, memoria y procedencia.

La existencia técnica de un órgano no crea por sí misma competencia política.

```text
BUILDING != GOVERNING
OBSERVATION != JUDGMENT
ADVICE != DECISION
MEMORY != CURRENT AUTHORITY
```

Para saber qué está vigente, consultar siempre:
