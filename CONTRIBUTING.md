# Guía de Contribución a Rudis 🏛️

¡Gracias por tu interés en aportar al ecosistema Rudis! Toda contribución (código, documentación, revisión de textos) ayuda a cimentar esta arquitectura.

## ¿Cómo aportar?

### 1. Proponer un cambio o idea
* Para debatir o proponer ideas generales, usa la pestaña **Discussions** (El Foro del Gremio).
* Para fallos concretos o propuestas estructuradas, abre un **Issue** usando nuestras plantillas oficiales.

### 2. Enviar Código o Modificaciones (Pull Requests)
1. Haz un **Fork** de este repositorio a tu cuenta.
2. Crea una rama para tu cambio (`git checkout -b propuesta/mi-mejora`).
3. Realiza tus cambios asegurándote de mantener la coherencia y el formato del proyecto.
4. Asegúrate de que los tests o validaciones locales pasen correctamente.
5. Haz un **Pull Request (PR)** hacia la rama `main` del repositorio principal explicando tus cambios.

> **Nota de Gobernanza:** Ningún cambio se integrará directamente a `main` sin haber pasado los tests de GitHub Actions y la revisión del equipo.
