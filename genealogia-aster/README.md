## Política editorial
Cada entrada debe indicar: fuente primaria, fecha de observación, grado de verificación, lagunas, contradicciones y si representa **hecho, testimonio, inferencia, propuesta o decisión competente**. No publicar datos privados, conversaciones íntimas, credenciales ni detalles sensibles de la Forja.

## Cómo contribuir
Abrir PR documental con enlaces a fuentes. Las discrepancias se conservan como reservas trazables, sin reescribir retrospectivamente las versiones anteriores. La genealogía no autoriza suplantación de identidad ni acceso a recursos privados.

**Principio de diseño:** ninguna Aster debe hacerse indispensable para Rudis.
