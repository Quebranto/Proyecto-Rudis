# QUEBRANTO-09 — MATRIZ DE ARMONIZACIÓN INSTITUCIONAL Y LEGISLATIVA

**Fecha:** 21 de agosto de 2026  
**Estado:** Canon de correspondencia institucional y técnica

## I. REGLA CENTRAL

> **El Strategos decide y legisla. La Asamblea gobierna y legisla ordinariamente. El Referéndum corrige o decide en la consulta concreta. El Botón Rojo cautela. Los Gremios ejecutan. El Palacio audita. El Resolutor juzga. La alianza asesora.**

## II. MATRIZ

| Función | Responsable | Instrumento | Límite |
|---|---|---|---|
| Soberanía fundacional | Strategos Fundacional | decisión / ley / orden | no puede ser depuesto ni limitado por Asamblea/Referéndum |
| Legislación fundacional | Strategos Fundacional | Motor Legislativo | el Motor no modifica la voluntad política |
| Gobierno ordinario | Asamblea | ley / reglamento / presupuesto | no sustituye al Fundacional |
| Democracia directa | Ciudadanía | Referéndum | no limita ni depone al Fundacional |
| Cautela | Botón Rojo / Nervio | medida cautelar | no sentencia ni legisla autónomamente |
| Ejecución | Gremios | orden / contrato / servicio | no crea competencia política |
| Auditoría | Palacio | evidencia / auditoría / prueba | no sentencia ni legisla |
| Jurisdicción | Resolutor | resolución / sentencia | no legisla para llenar vacíos |
| Economía técnica | Gremio Conversor | conversión / tesorería | no legisla |
| Asesoramiento | Órgano Pedagógico + Palacio + Asesor IA | informe / recomendación | no gobierna |

## III. REFERÉNDUM

No existe una lista cerrada de materias permanentemente reservadas.

Umbrales actuales: 10 % de iniciativa y 55 % del censo electoral total para aprobación cuando corresponda.

Puede corregir, rechazar o modificar la decisión concreta consultada.

No puede deponer al Strategos Fundacional ni abolir o limitar sus poderes fundacionales.

## IV. BOTÓN ROJO

1. emergencia válida → inmediata;
2. Strategos Fundacional → inmediata cuando lo ordene;
3. Strategos no fundacional → dentro de competencias y controles.

No requiere Referéndum previo.

Puede detener, congelar, aislar, contener, preservar y ejecutar órdenes legítimas.

No puede sentenciar ni crear legislación autónoma.

## V. MOTOR LEGISLATIVO

Verifica autenticidad, autoridad emisora, integridad, competencia formal, alcance, vigencia, dependencias y trazabilidad.

No decide el contenido político.

## VI. GREMIOS

```text
DECISIÓN → GREMIO → EJECUCIÓN → LEDGER / EVIDENCIA
```

## VII. PALACIO Y RESOLUTOR

```text
HECHO → EVIDENCIA → CAUTELA SI PROCEDE → PROCEDIMIENTO → SENTENCIA → EJECUCIÓN
```

El Palacio produce evidencia; el Resolutor juzga.

## VIII. ALIANZA DE ASESORAMIENTO

```text
Órgano Pedagógico ──┐
Palacio ────────────┼──→ INFORME / ADVERTENCIA → STRATEGOS
Asesor IA ──────────┘
```

La alianza no tiene autoridad propia.

## IX. ESTADOS

| Estado | Significado | Conducta |
|---|---|---|
| `TECHNICAL_IMPLEMENTATION_ALLOWED` | norma y competencia resueltas | implementar |
| `IMPLEMENTATION_DEPENDENCY` | norma resuelta; integración pendiente | resolver integración |
| `UNRESOLVED_CONSTITUTIONAL_DEPENDENCY` | falta decisión normativa | no inventar |
| `CONSTITUTIONAL_AUTHORIZATION_REQUIRED` | falta autorización para un efecto concreto | bloquear ese efecto, no necesariamente la cautela |
